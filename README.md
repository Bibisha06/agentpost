# AI post Generator 

An AI-powered agent that generates genuinely funny, internet-native reddit like posts for any given topic.

It leverages a multi-agent workflow to:
- **Analyze Topics**: Determine if real-world news context is required for the joke.
- **Fetch Real-Time Context**: Pull in and rank current news articles to keep references fresh.
- **Reference Internet Culture**: Use RAG with historical Reddit data to perfectly match authentic internet tone and formatting.
- **Critique & Refine**: Iteratively evaluate and rewrite the generated drafts until they pass a strict AI critic's standards for humor and originality.
